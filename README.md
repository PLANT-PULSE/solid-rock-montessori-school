# Morning Dew Academy website

A responsive static website for Morning Dew Academy in Bronyibima – New Site, Elmina, KEEA District, Central Region, Ghana.

Built with plain HTML, CSS and vanilla JavaScript. Open `index.html` directly or run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Key features

- Blue, yellow and white school branding
- Official Morning Dew Academy crest and genuine school photographs
- Shared responsive header and footer
- Admission and general enquiry forms that open prefilled WhatsApp messages
- Gallery filters and lightbox
- Mobile navigation, scroll effects and page transitions
